openclaw-personal

A private OpenClaw AI agent operated by MONSTER HOOPS / Joohan Lee for personal use.

What it is

openclaw-personal is a personal AI assistant built on OpenClaw. It is used only by its owner, through a private Telegram chat, to look things up in the owner's own Google accounts. This is a privately operated, single-user application for the owner's two Google accounts. It has no public registration or user login, and it is not affiliated with, endorsed by, or operated by Google.

How it uses Google data

The app asks for read-only access to the owner's own Google accounts, for these purposes only:

  • Gmail (gmail.readonly): search and read the owner's messages when the owner asks, for example "find the latest email from a vendor".
  • Google Calendar (calendar.readonly): list the owner's events, for example "what is on my schedule tomorrow".
  • Google Drive (drive.readonly): search and read the owner's files when the owner asks.

The app cannot send email, create or change calendar events, or create, edit or delete Drive files. It requests no write permission.

Privacy

Read how Google user data is accessed, used, stored and shared in the Privacy Policy.

openclaw-personal's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
